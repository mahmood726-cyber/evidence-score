How should we fix this?

The fix determines how scores change — and whether it's just a bugfix or a deeper redesign

A

Bugfix Only: Normalize MA IDs

Extract review_id + __variant from both formats to create a common key. Minimal code change (~10 lines). Scores will drop ~20 points on average for contradicted MAs. Keep current 5 components and weights.

Pro: Fast, targeted, preserves existing architecture
Con: Doesn't address arbitrary weights or degenerate component design
B

Fix + Recalibrate: Fix bug + justify weights

Fix the ID mismatch, then recalibrate weights empirically. Use sensitivity analysis (vary weights, measure rank stability). Potentially adjust grade thresholds since mean score will drop from 69 to ~49. Add a 6th component (e.g., sample size adequacy separate from power).

Pro: Defensible for Lancet Digital Health submission
Con: More work, need to regenerate all results + dashboard
C

Full Redesign: Evidence-based composite

Rebuild scoring from scratch with validated methodology: principal component analysis to derive data-driven weights, external validation against known "fragile" vs "robust" MAs, confidence intervals on scores, and Bland-Altman agreement with expert ratings.

Pro: Publishable methodology, novel contribution
Con: Much larger scope, needs expert ratings dataset
